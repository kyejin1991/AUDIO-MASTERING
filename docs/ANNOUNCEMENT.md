# audio-mastering Community Edition v0.1.0 공개

audio-mastering Community Edition v0.1.0을 공개했습니다.

AI Mastering Lab에서 공개 가능한 Community 레이어만 분리한 오픈소스 프로젝트입니다.

Community는 미완성 버전이 아니라 공개 가능한 오디오 분석 및 수동 워크플로우 레이어입니다.

Pro는 별도의 비공개 제품 레이어입니다.

## 포함

- 프로젝트 생성
- LUFS / 라우드니스 분석
- Spectrum 분석
- Dynamics 분석
- Stereo 분석
- Streamlit 기반 Community UI
- 기본 DSP 모듈 구조

## 포함되지 않는 것

이 공개 저장소에는 Pro 엔진이 포함되어 있지 않습니다.

의도적으로 제외된 항목:

- AI Master Assistant
- AI 마스터링 의사결정 엔진
- Pro 렌더링 오케스트레이션
- 장르별 프로필
- 상업용 프리셋
- Pro QC 워크플로우

# audio-mastering Community Edition v0.1.0

I released audio-mastering Community Edition v0.1.0.

It is the open-source Community layer of AI Mastering Lab, focused on audio analysis and manual workflow tools.

Community is not an unfinished version. It is the open-source layer.

Pro is a separate proprietary product layer.

## Included

- Project creation
- LUFS / loudness analysis
- Spectrum analysis
- Dynamics analysis
- Stereo analysis
- Streamlit-based Community UI
- Basic DSP module structure

## Not Included

The proprietary Pro engine is not included in this public repository.

The following components are intentionally excluded:

- AI Master Assistant
- AI mastering decision engine
- Pro rendering orchestration
- Genre-specific profiles
- Commercial presets
- Pro QC workflow
