# AI Mastering Lab Community Edition v0.1.0

This is the first public community release of AI Mastering Lab.

## Included

- Loudness analysis
- Spectrum analysis
- Dynamics analysis
- Stereo analysis
- Basic DSP modules
- Manual mastering workflow
- Optional stem separation interface

## Not Included

This Community Edition does not include the proprietary Pro engine:

- AI Master Assistant
- Automatic mastering decision engine
- Genre-specific profiles
- Pro rendering orchestration
- Commercial presets

## Notes

This release includes third-party open-source components and integrations. See `THIRD_PARTY_LICENSES.md` and `NOTICE` for details.
